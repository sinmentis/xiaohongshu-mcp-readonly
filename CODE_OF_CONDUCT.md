# Code of conduct

We want project discussions to be useful, safe, and focused on the work.

## Expected behavior

- Be respectful and specific.
- Critique ideas and code, not people.
- Give enough context for others to reproduce a problem.
- Protect account data, credentials, and private communications.
- Accept maintainers' decisions on project scope and security boundaries.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Publishing private information without permission.
- Deliberately bypassing the read-only scope or safety controls.
- Spam, promotional content, or repeated off-topic demands.

## Enforcement

Maintainers may edit or remove content, close contributions, or restrict
participation when behavior harms the project or its community.

Report conduct concerns privately through the repository's security advisory
channel when disclosure in a public issue would expose personal information.
