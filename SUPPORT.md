# Support

Use GitHub Issues for reproducible bugs and focused feature requests.

Before opening an issue:

1. Read [docs/troubleshooting.md](docs/troubleshooting.md).
2. Confirm the selected site matches the account.
3. Include the operating system, architecture, browser source, command-line
   flags, and redacted logs.
4. Remove cookies, QR payloads, tokens, account identifiers, and proxy
   credentials.

This project cannot provide account recovery, restriction removal, platform
support, or guarantees against automated-access challenges.

Report vulnerabilities privately through [SECURITY.md](SECURITY.md).
